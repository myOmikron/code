
# TypeReport

One primary type\'s count against its empirical target.  A third axis beside `BucketReport` and `CurveBucket`, kept separate because it measures a different thing: the buckets are functional (a creature can be ramp), the types are material — and a deck can sit inside every functional quota while holding forty creatures.
