
# AxesPosition

`Diagnostics.cedh_position` (diagnostics.py names the field; this is its value type). `archetype_class` rather than the task shorthand `class` — a reserved word. `speed`/`interaction` are `None` only when the corresponding axis has no defined value for this deck (a deck with no complete candidate line has `speed=None`); `below_floor` depends only on `interaction` against the class\'s own floor, never on speed.
