
# ThemeLean

A theme the suggestions read as, that the deck itself does not play.  Offered so the reader can exclude it in one click. Not applied — the whole point is that this is a judgement only the deck\'s owner can make, and an off-theme build is a choice, not a mistake to be corrected.
