
# CurvePoint

One mana value\'s share of the deck\'s target curve.  A *share*, not a count, because a target is `share x spell count` and the two sides of that product belong to different people: the builder owns the shape, the deck owns how many spells there are. Shares that do not sum to 1 are renormalised rather than refused — a shape is a shape whatever arithmetic the client did — see `composition.apply_curve`.
