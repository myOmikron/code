
# TypalShare

A creature type\'s share of the deck\'s typal identity.  Kept apart from `ThemeShare` rather than merged into one list. They come from different axes and answer different questions — \"what does this deck do\" against \"what is it made of\" — and a Goblin deck is usually also an aristocrats or tokens deck. Merging them would force a card to choose.
