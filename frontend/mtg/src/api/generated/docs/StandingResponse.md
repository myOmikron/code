
# StandingResponse

One row of the standings  Every percentage is in basis points — 10 000 is 100 % — which is also the precision it is meant to be shown at. Two rows whose numbers render the same really are equal, so a reader checking the table by hand never finds a tie broken by a digit that was not on screen.
