
# ExtraTurnRule

How much extra-turn play a bracket tolerates  Three values rather than a yes/no, because the published rule is not one: Exhibition plays no extra turns at all, Core and Upgraded ask only that they are not *chained*, and the top two ask nothing. A single Time Warp is a legal Core card, so a boolean here could only be wrong in one direction or the other.
