
# CardRarity

Rarity of a printing, as Scryfall reports it  The order of the variants is the ladder, commonest first — the same order the set symbol\'s colours run in. Keep it that way: sorting a collection by rarity means sorting by this, and a separate rank function would be a second place to get it wrong.  [`Self::Special`] and [`Self::Bonus`] sit at the end because they are not a step on that ladder — they mark the timeshifted and bonus sheets, which have no place among the four.
