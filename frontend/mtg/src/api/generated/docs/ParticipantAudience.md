
# ParticipantAudience

Who may see a tournament\'s roster at all  A separate, later gate than [`Visibility`]: visibility decides whether a viewer reaches the tournament in the first place, this decides — once they have — whether they may see who is playing in it. Staff see the roster in full no matter what this is set to; see [`public::roster_view`](crate::models::tournament::public::roster_view) for exactly how the two combine.
